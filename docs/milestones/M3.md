## Built

The sole resumable splitter drives both batch and live parsing. Sealed statements
are parsed once; UTF-8/CR/header/fence prefixes stay held back; a closed-copy tail
provides partial output and retains the last successful output on parse failure.
Cutoff-sensitive lexical diagnostics remain provisional until their statement seals.
Message byte budgets count original selected bytes, including CRLF before normalization.

Session push/finish/reset/snapshot return Update with named patch batches, incremental
prose and diagnostics. Reverse dependency revisions drive invalidation; static
subtrees can be reused while canonical budgets are recomputed. Dynamic expressions
remain structural deferred props; no evaluator, query dispatch or action execution
is implemented. A provisional action alias cannot publish a handle through a sealed
consumer. Checked replay handles parent/index ordering, removals, moves, snapshots,
epochs and sequence gaps. The replay CLI prints each batch and retained tree.

The core owns canonical JSON encoding. IR, patch and std-library byte goldens are
checked under ordinary and preserve_order serde_json backends. Semantic maps use
ordered tagged pairs; the std hash remains d19a769bd510997ce786ade4d60db23d.

## Spec changes and why

- §§2.9,3: retain selected raw message bytes for pre-normalization budgets and seal
  on a completed closing fence; a CRLF budget fixture exposed M2's normalized count.
- §§3.7,13: distinguish incremental diagnostic additions from the authoritative
  current list; semantic diagnostics may conservatively stay provisional until
  finish. This makes cutoff withdrawal explicit without stale host diagnostics.
- §§5.5,6.3: scope evaluated wire props to M4; M3 carries structural deferred ASTs,
  avoiding unstable expression-arena indices or an early evaluator.
- §6.5: typed maps are tagged ordered pairs. Sorted JSON object keys otherwise
  destroy insertion order and collide with wire value tags. Library metadata and
  defaults remain ordinary sorted objects; six old map goldens migrate explicitly.
- §§6.2–6.4: specify root attachment and deterministic final-tree diff ordering,
  coalescing, empty pushes, idempotent finish and snapshot sequence consumption.
- §§6.5,8.2,12.2: compact canonical golden bytes plus a file LF outside the hash;
  implements the approved GPUI preserve_order finding without changing std hash.
- §§12.1,12.3,12.7: strict checkpoint/session-script metadata and replay formatting,
  positive chunk size with default 64; mutation coverage includes Session/patches/
  canonical encoding. Extend I6 through provisional reverse dependencies.
