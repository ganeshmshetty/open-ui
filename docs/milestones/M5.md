# M5 — prompt, feedback, stored messages and events (SPEC §§4.6,9,12,13)

Branch: `milestone/m5`. Scope follows the M5 done criteria: `prompt`, `feedback`
and `message` fixtures pass, and prompt bytes are identical on macOS and Linux CI.
No M4 runtime is included; message construction and replay are static.

## Built

`genui-prompt` now implements the pure generator for sections S1–S11. It renders
the library header, optional preamble, capability-filtered component signatures,
builtin one-line documentation, state/forms/actions, tool and ref rules, selected
library examples, fixed rules and host additions. The text is LF-only and ends
with one LF; `Prompt` carries an xxh3-128 digest and `PROMPT_TEMPLATE_VERSION`.
Component and function lines come from the Library Spec; the builtin table is
checked against the core builtin list. Examples are selected in catalog order,
skipped when they use an unavailable component, and validated in tests.

The per-turn block renders the ref catalog and a `ui-diag` feedback block.
`render_event` emits the fixed-order `ui-event` JSON, and
`render_stored_message` replays stored text with `ui`/`ui vN` fences and no
metadata.

Core additions:

- `feedback::render` filters to final FB codes, excludes Info and provisional
  lines, sorts Fatal/Error/Warning then source position (or statement name when a
  span is absent), merges duplicates by `(code, stmt, path)` and caps at 20 lines.
  Argument, slot and required-argument diagnostics carry precise feedback
  locations; enum details include found/expected values and missing-required lines
  include the exact catalog signature.
- `message::{StoredMessage, StoredSegment, LibRef, StateSnapshot, ModelEvent}`.
  Stored messages preserve segments, prompt digest, completion, fallback text,
  final non-provisional diagnostics and an optional state snapshot as plain data.
  `library_mismatch` emits Info `lib.mismatch` without blocking replay.
- `Session::{feedback, fallback_text, stored_message, restore}`. `restore`
  re-parses the stored program on the batch path, retains `restored_state`, and
  emits the identity diagnostic after finishing. Static fallback follows each
  component's `to_text`; dynamic props contribute empty text until M4 evaluation.
- `genui-cli prompt`, `feedback` and `message` are runnable demos. `message`
  prints canonical stored JSON, or its model-facing replay with `--replay`; `--cut`
  records an unfinished stream.
- A `prompt` fuzz target checks deterministic, LF-only output for arbitrary
  `PromptOptions` JSON. No fuzz campaign was run in M5, per the task constraints.

## Spec changes and why

- §§4.6,9.1: fix the prompt layout, signature/type spelling, section omission,
  builtin documentation, per-turn block, prompt digest and versioning. This is
  ROADMAP item 3's actual wording, now pinned by goldens.
- §9.2: storage uses `StoredSegment` with a language major; replay fences and
  metadata exclusion are explicit; `lib.mismatch` is Info and replay continues;
  `StateSnapshot { v, values }` and pre-M4 restore behavior are defined.
- §9.3: event JSON has a fixed field order and explicit optional-field omission,
  making event text independent of JSON map backends.
- §12.1–12.2,12.7: add prompt/feedback/message fixture files and comparison rules,
  add the three CLI inspection commands, and record the new demo behavior.
- §4.7: state that static fallback leaves dynamic props empty until M4.
- `lib.mismatch` moved from `conformance/deferred.json` to covered diagnostics.

## Remaining gaps

- M4 runtime is still absent, so query/ref delivery, state writes, action events
  and evaluated fallback are not exercised. `Session::restore` retains but does not
  apply state.
- ROADMAP item 4 (model evaluation set, recorded real-model transcripts and the
  S2/resync measurements) is not completed; it needs model access and recorded
  transcripts. The deterministic prompt/feedback/message harness it would use is
  now in place.
- Mutation testing remains advisory; no M5 inventory/survivor campaign was run.
- No files under `research/openui/` were read, searched or copied.
