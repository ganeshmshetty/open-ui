# M6 — GPUI skeleton, retained tree, layout/text components, theming, gallery and streaming dashboard

Branch: `milestone/m6`, based on `35d84e8`. This report covers DESIGN.md draft
0.3 and SPEC §14.1 M6. Inputs/forms are M7; data tables, lists, tabs, image
loading and renderer panic containment are M8.

## Built

- **Pins and build.** `genui-gpui` activates exactly `gpui-kit`, `gpui-component`
  and `gpui-base` at `=0.8.0` and `gpui-pre` at `=0.3.9` (SPEC §10.9).
  `Cargo.lock` is committed. The renderer MSRV is Rust 1.99.0 because
  `gpui-pre 0.3.9` uses `std::hint::cold_path`; `rust-toolchain.toml` selects it.
- **`UiView`.** A retained tree of path-keyed nodes, child slots and statuses;
  `apply` mutates before a frame with `&mut Window`; `enqueue` drains at most
  once at the start of `render`. Batches are atomic, epoch-aware and
  sequence-checked; gaps and bad IDs request a snapshot and never panic.
  Reset/snapshot batches replace the tree. Container nodes are
  `Entity<NodeView>`; `Text`/`Markdown`/`Code` update through their nearest
  container entity (measured trade-off in SPEC §10.6). Chart plots and Images
  use `AnyView::cached` with definite dimensions (SPEC §10.1).
- **Components.** Column, Row, Grid (responsive to a 220 px minimum cell), Card,
  Divider, Heading (4 levels + section spacing), Text (sizes, tones, bold,
  mono), Markdown, Code (copy action), Badge, Alert, Image placeholder/fallback,
  Button (visual only; interaction/gating is M7), Stat, Facts and Chart. Unsupported M7/M8 kinds render a
  labeled placeholder; Form, List, Tabs and Tab show their children under the
  placeholder.
- **Theming.** `genui-gpui::theme::UiTheme` is the only module with color or
  pixel literals. It maps DESIGN §§2–5 to gpui-base semantic tokens, adds
  light/dark tones and the Okabe-Ito chart palette, supplies host overrides
  (colors, fonts, radius multiplier), installs the component/base themes, and
  tests WCAG AA for every tone pair in both modes.
- **Formatting.** DESIGN §6.12 number, compact, currency, percent, delta and
  date formats with en-US rules, true minus, tabular figures and chart ticks.
- **Gallery.** `gallery` loads all 24 exemplars and the synthetic state sheet;
  `--list` prints node/deferred counts, `--screenshot DIR` writes one PNG per
  example and mode (50 PNGs), `--inspector` adds the debug inspector, and
  `--self-test-freshness` proves the §10.1 one-batch freshness rule.
- **Streaming dashboard.** `dashboard` streams an exemplar through `Session` into
  `UiView`, applies each batch before the frame, prints/persists the patch log,
  captures a screenshot and writes metrics. `--headless` runs the test-support
  renderer; `--replay` re-applies a recorded JSONL log without panic;
  `--stress N` generates a budget-safe many-node program.
- **Inspector.** `genui-gpui::inspector` renders the retained tree, bounded patch
  log and diagnostics list. It is host-owned, debug-only and does not touch the
  IR or protocol (SPEC §10.13).
- **Examples.** Percent values in 01/02/22 were corrected to Design §6.12
  semantics (a percent value is already a percentage). All 24 exemplars still
  validate.

including the GPU-backed framework); the retained tree itself is much smaller,
but the process number is reported rather than hidden. The example dashboard is
well inside the frame budget.

## Screenshot review against DESIGN.md

Reviewed the full 50-PNG set plus the state sheet in both modes. Fixed findings:

- Badges and buttons were stretched by a Column's default stretch; they now keep
  natural width (DESIGN §6 rules 4/7).
- `Tag::custom` arguments were reversed, making badge text invisible; corrected.
- Chart value labels wrapped and the plot overlapped its summary; widened the
  axis and reserved the category-label height.
- Kit bar ticks were not round; replaced with canvas bars and round 1/2/5×10ⁿ
  ticks (DESIGN §6.11).
- Line charts had no null gaps; canvas lines now break and draw singleton points.
- The chart failure text was muted instead of `danger.fg`; fixed.
- Fractional percent exemplars rendered `0%`; corrected to percent values.
- Inspector mode squeezed the program under the new panel; UiView now accepts a
  host width cap.

Logged findings (not fixed in M6, with reasons):

- **Grid gap.** DESIGN §6 rule 5 says `gap: 3` (12 px) by default; the std
  catalog's resolved default is `gap: 2` (8 px). The renderer cannot tell an
  omitted argument from the default, and changing the catalog would change the
  M2 Library Spec hash. M6 follows the catalog and logs the 8 px deviation.
- **Markdown inline code and links.** The pinned component `TextView` still
  paints inline code with an accent tint and links inherit the foreground in the
  captured set, despite a custom inline-code style and component link colors.
  A custom Markdown renderer or a pin-supported fix is M8 work.
- **Chart hover tooltips** are not implemented; canvas charts are static in M6.
- **Streaming fades and reduced motion** (DESIGN §8) are not implemented; M6
  demonstrates steady retained updates without animation.
- **Image** is the DESIGN pending/failed box only; the host loader and cached
  bytes are M8.
- **`Code` syntax highlighting** is off because the renderer reports
  `code_highlight: false`; the prompt/core fallback stays honest.
- **`render.panic`** remains deferred to M8; M6 adds no subtree panic boundary.
- **`UiEvent` delivery** is M7. The core `UiEvent` type itself is not defined
  until the runtime work; M6's `UiView` exposes apply/enqueue/capabilities and
  renders button anatomy, but no event is emitted and no action executes.
- **Grid cap / responsive width** uses the message width and the parent-assigned
  width; a full measured layout pass (gpui-kit `measure`) remains M8.
