# M8 — Data components, panic containment, host loop and v0.1 readiness

Branch: `milestone/m8`, merged into `main` at `61e3022` after resolving the M7
input/form overlap. The merged tree contains both M7 (inputs/forms/focus/
accessibility) and M8 (data components, panic containment, sample host,
transcripts). No git tag was created (owner decision).

## Built

- **List.** At or below 100 children, a plain column with the DESIGN §7 marker
  gutter (4 px dot or ordered number in a 16 px gutter), 8 px item gap, loading
  skeleton rows, refreshing dimming and a failure caption. Above 100 children,
  the kit virtual list over `ListState<GenuiListDelegate>`: only visible item
  `NodeView`s are created on demand, the gutter/numbering/gap/loading/empty
  behavior is preserved, and the ordered gutter widens for the widest number.
  Empty lists render nothing.
- **Table.** Kit `DataTable` over `TableState<GenuiTableDelegate>`: sticky header,
  row virtualization, row selection, sortable headers, resizable columns,
  horizontal scroll, empty/loading/error states, §6.12 cell/header formatting,
  right-aligned numeric columns and a full-value tooltip. Rows are parsed once,
  the duplicate wire `rows` prop is dropped from the retained tree, and a
  `rows_rev` cache key avoids reparsing on unrelated updates.
- **Tabs/Tab.** DESIGN tab bar and selected-panel mount; local selection; Left/
  Right/Home/End keyboard switching; bound selection emits a path-addressed
  `Edit`.
- **Image loader.** Host-owned `request_image` / `deliver_image` / `fail_image`;
  pending and failed boxes, loaded image with cover/contain; 8 MiB, 4096 px,
  16 MP and 256-source caps; decode panics become a failed image. The renderer
  performs no I/O.
- **Chart polish.** Pointer hit-testing and an overlay tooltip for the nearest
  category using §6.12 number formatting; refresh dimming; loading skeleton.
- **Motion.** 150 ms ease-out fade on newly inserted sealed nodes, 1.2 s skeleton
  pulse, and a props-change/reinsert generation so updates do not re-animate.
  `with_animation` follows `App::reduce_motion`; screenshot hosts request it.
- **Panic containment.** Every node builder runs under `catch_unwind`; a panic
  becomes "This part could not be shown", one `render.panic` diagnostic per node
  revision (capped at 64), and quarantine after 3 panics until props change. The
  `PanicProbe` injection kind is not in the std catalog. `CONTAINMENT_ENABLED`
  exposes the `panic = "unwind"` requirement.
- **Path-addressed events.** `UiView` emits the core path-addressed `UiEvent`
  (`Activate`/`Edit`/`Blur`) directly after the M7 merge. `Session::activate_at`,
  `edit_at` and `blur_at` remain convenience methods for hosts holding a path.
  Buttons gate on sealed/enabled/actionable state; Tabs and inputs emit `Edit`.
  A temporary `RendererEvent` bridge used during M8 development was removed at
  integration.
- **Core host APIs.** `Session::preload_ref` (same catalog/nesting/byte caps),
  `Session::state_snapshot`, `Session::freeze -> FrozenMessage`, and
  `Session::restore` preserving undeclared snapshot values for host round-trip.
- **Reference host.** `genui-gpui::host::SampleHost` with deny-by-default
  allowlists, ref/query delivery, `say`/`emit` recording, https + host allowlist
  for `open` and images, bounded request loop and a serializable decision trace.
- **Sample host.** `sample-host` streams a transcript through `Session` and
  `UiView`, captures 25/50/75/100% (+ frozen/final/restored), supports
  `--freeze-at`, `--restore`, `--regenerate` and `--replay-all`, checks the
  recorded prompt text and digest, and writes a run report. No network.
- **Transcripts.** 20 checked-in `eval/transcripts/*.json` generated from
  exemplars with deterministic chunks, preloaded refs, query results, button
  events and full prompt. Every file is labelled `scripted-fixture`.
  `genui-cli transcripts [--record|--verify]` replays exact canonical patches,
  state, model events, diagnostics and request trace.
- **Table stress.** `table-stress --rows 50000` through a ref-backed Session +
  UiView; reports visible ranges, construction/stable frames, apply/parse time
  and RSS.
- **Docs/release.** README quickstart, `docs/host-guide.md`,
  `docs/security-review.md`, `docs/release/v0.1-checklist.md`, DESIGN 0.4,
  SPEC/CHANGELOG updates, DECISIONS conflict resolution + M8 defaults.
