# v0.1 release checklist

Status: **ready to tag by the integrator; not yet tagged.** `milestone/m8` now
contains the merged M7 input/form/focus/accessibility work and the M8 data/host
work. This checklist records the merged-tree gates; the tag itself is the
integrator's step.

| --- | --- | --- |
| Format | `cargo fmt --all -- --check` | pass |

Local builds use a shared target directory with `CARGO_PROFILE_DEV_DEBUG=0` and
`CARGO_INCREMENTAL=0` to bound disk use; this does not change runtime behavior.

## Release contents

- `Cargo.lock` committed; exact pins in SPEC §10.9.
- Version `0.1.0`; crate prefix is temporary (`genui-*`). Project naming is an
  owner decision (ROADMAP item 10).
- README quickstart and `docs/host-guide.md`.

  table and 10k virtualized-List stress binaries.
- `docs/security-review.md` and the tests it cites.

## Open items before publishing

- **OS-level accessibility is unverified.** The pinned test platform installs no
  accesskit adapter, so the accesskit projection is measured, not the platform
  tree.
- **No live model run.** Transcripts are `scripted-fixture`; the real-model loop
  in SPEC §12.7 still needs credentials and a recorded run. Do not describe the
  checked-in transcripts as model evidence.
- **v0.1 tag** is intentionally not created; the integrator owns the tag.
- **License** is not chosen. ROADMAP item 10 suggests MIT/Apache-2.0 but the owner
  must decide; no LICENSE file was added.
- Performance/memory misses recorded in SPEC §10.6 and PROGRESS: 2,000-node
  stream p99 11.6 ms (target 8), 50k construction 323 ms and 772 MB process RSS.
  They are reported, not waived.
- Mutation/fuzz campaigns were not run for this slice (task constraint); the
  existing advisory workflow is unchanged.
